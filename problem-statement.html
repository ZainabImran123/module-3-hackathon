Service Booking Platform Challenge

Streamlining discovery and management between customers and local service providers.

1. Problem Statement

Customers often find local service providers through scattered WhatsApp messages, social media calls, or phone lists. This project builds a focused Minimum Viable Product (MVP) that makes discovering a provider and managing a service request simple, trackable, and unified.

2. User Roles & Capabilities
Customer
  • Browse & filter providers by category
  • Submit structured booking requests
  • Track status changes in real time
  • Submit 1–5 star ratings on completion
Service Provider
  • Manage provider profile details
  • View incoming booking queues
  • Accept, reject, or update request statuses
  • Progress work to In Progress / Completed
3. Required Booking Workflow
1 Login → Search Provider Profile
2 Submit Booking Request (with Unique ID)
3 Provider Accepts → Changes to In Progress
4 Provider Marks Completed → Customer Leaves Review
